## Reproducibility

Raw traces are intentionally not committed to normal Git history because the corpus is hundreds of megabytes and is reproducibly generated by `.github/workflows/embench.yml`. The workflow, bare-metal runtime, trace reconstruction script, exact Embench commit and audit assertions are versioned in this repository.

The validated raw corpus is retained as the GitHub Actions artifact above while its retention period is active. If the artifact has expired, rerun the pinned workflow at the recorded ATHENA commit (or a later explicitly audited compatible commit) and require the same 38/19/revision assertions before using the regenerated traces.

## Scientific status

These traces are dynamic instruction traces used as experimental input. Structural templates mined from them are not cycle measurements and must not be reported as speedup.
